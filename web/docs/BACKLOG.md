## Справочник оснащения

Сейчас формы расходов и преимуществ предлагают вручную ввести технический ключ. Предлагаемый сценарий позволяет выбрать понятное название, автоматически получить одинаковый ключ для одинакового оснащения в обеих группах и ввести произвольное название при необходимости. Идентификация произвольного оснащения требует отдельного согласования.

Предварительные примеры для обсуждения с Android и Backend.

| Оснащение                      | Возможный ключ     |
| ------------------------------ | ------------------ |
| Зимняя резина                  | `winter_tires`     |
| Летняя резина                  | `summer_tires`     |
| Сигнализация                   | `alarm_system`     |
| Автозапуск                     | `remote_start`     |
| Мультимедиа                    | `multimedia`       |
| Камера заднего вида            | `rear_view_camera` |
| Парктроники                    | `parking_sensors`  |
| Дополнительный комплект дисков | `extra_wheels`     |
