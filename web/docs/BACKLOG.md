## Справочник оснащения

Формы расходов и преимуществ используют свернутую настройку «Связать одинаковое оснащение». Ранее сохранённые ключи остаются доступны для редактирования. Предлагаемый сценарий позволяет выбрать понятное название, автоматически получить одинаковый ключ для одинакового оснащения в обеих группах и ввести произвольное название при необходимости. Идентификация произвольного оснащения требует отдельного согласования.

Предварительные примеры для обсуждения с Android и Backend.

| Оснащение                      | Возможный ключ     |
| ------------------------------ | ------------------ |
| Зимняя резина                  | `winter_tires`     |
| Летняя резина                  | `summer_tires`     |
| Сигнализация                   | `alarm_system`     |
| Автозапуск                     | `remote_start`     |
| Мультимедиа                    | `multimedia`       |
| Камера заднего вида            | `rear_view_camera` |
| Парктроники                    | `parking_sensors`  |
| Дополнительный комплект дисков | `extra_wheels`     |

## Результаты проверки

- WEB-09 и WEB-10 проверены сценариями в Chrome. Пользовательское исследование с покупателями остаётся частью общего плана MVP.
- WEB-11 использует фотографии модели из Wikimedia Commons для новых сессий seeded Mock API. Авторы и лицензия указаны в [README](../README.md).
- WEB-25 проверен на обычной и восстановленной сессиях, принудительном `503`, временном отсутствии сети, некорректном `200` и недействительном токене. Подробности в [архитектуре Web](ARCHITECTURE.md#диагностика-загрузки-оценки).
