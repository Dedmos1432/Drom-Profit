# Drom Profit Web

Веб-фундамент P0 на React, TypeScript и Vite. Продуктовые маршруты содержат заглушки. Каталог UI Kit показывает реальные компоненты на демонстрационных данных.

## Запуск

Node.js `^20.19.0`, `^22.13.0` или `>=24` и npm. Проверено на Node.js 24.11.1 и npm 11.6.2. Команды выполняются из `web/`.

```sh
npm ci
npm run dev
```

Откройте [UI Kit в dev-режиме](http://localhost:5173/ui-kit) или используйте порт, который Vite напечатает при запуске. Продуктовые заглушки доступны по `/`, `/cars/new`, `/cars/demo-1` и `/comparison`.

## Сборка и проверки

```sh
npm run typecheck
npm run lint
npm run test
npm run build
npm run preview
```

`npm run build` генерирует CSS-токены, проверяет типы и создаёт `dist/`. При размещении сборки настройте возврат `index.html` для клиентских маршрутов. В production-сборке адрес `/ui-kit` попадает на страницу 404.

`npm run test:watch` запускает проверки с наблюдением за файлами. `npm run format` форматирует локальные исходники и документацию.

## Переменные окружения

Используйте `.env.example` как образец для локального `.env.local`. После изменения переменных перезапустите dev-сервер, для preview пересоберите приложение.

| Переменная          | Значения и значения по умолчанию                                                                       |
| ------------------- | ------------------------------------------------------------------------------------------------------ |
| `VITE_API_MODE`     | `mock` или `real`. По умолчанию `mock` при `dev` и `real` при production build                         |
| `VITE_API_BASE_URL` | HTTP(S) базовый URL. Пустое значение использует текущий origin в mock и `http://localhost:8000` в real |

Переменные `VITE_*` публичны в клиентской сборке. Токен сессии передаётся в API-клиент во время выполнения. Для real-режима согласуйте доступные origin с владельцем backend.

## API и токены

- `npm run api:generate` читает `../shared/openapi.yaml` и обновляет `src/shared/api/schema.ts`.
- `npm run mock:worker` обновляет поставляемый MSW worker. В mock доступны создание демонстрационной сессии и чтение демонстрационной выборки из общих fixtures.
- `npm run tokens:generate` синхронизирует CSS-переменные с `docs/design-tokens.json`. Dev и build запускают генерацию автоматически.
