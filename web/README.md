# Drom Profit Web

Веб-клиент P0 на React, TypeScript и Vite. Поддерживает анонимную сессию, сохраняемую выборку, импорт с предпросмотром, ручное добавление и удаление автомобилей. В карточке можно редактировать характеристики, вести расходы, преимущества и заметки, подтверждать денежные группы и смотреть экономическое саммари. Сравнение двух или более машин показывает экономические результаты и характеристики в таблице. Каталог UI Kit доступен в development-режиме.

## Запуск

Node.js `^20.19.0`, `^22.13.0` или `>=24` и npm. Команды выполняйте из `web/`.

```sh
npm ci
npm run dev
```

Откройте [локальную выборку](http://localhost:5173/) или используйте порт, который Vite напечатает при запуске. [Добавление](http://localhost:5173/cars/new), [ручной ввод](http://localhost:5173/cars/new?method=manual), [сравнение](http://localhost:5173/comparison) и [UI Kit](http://localhost:5173/ui-kit) доступны по своим маршрутам. Адрес `/cars/:carId` открывайте из строки сохранённого автомобиля.

## Проверка в mock-режиме

По умолчанию dev использует `mock` и сценарий `empty`. Для первого посещения откройте приложение в новом профиле браузера или сбросьте mock-данные по инструкции ниже. Выборка будет пустой.

1. Введите демоссылку в панели «Моя выборка» и нажмите «Добавить». Откроется редактируемый предпросмотр с пометкой «Демо-источник».
2. Измените модель или цену и нажмите «Сохранить автомобиль». Затем добавьте второй автомобиль через «Добавить вручную». В ручной форме обязательны марка, модель и положительная целая цена.
3. Перезагрузите страницу. Автомобили остаются в выборке. Откройте карточку, проверьте её характеристики и вернитесь в выборку.
4. Выберите два автомобиля и нажмите «Сравнить автомобили». Для удаления из выборки откройте подтверждение, проверьте отмену, затем подтвердите удаление.

Синтетические ссылки принимает локальный Mock API. Вставляйте их в поле импорта.

| Результат                    | Ссылка                                              |
| ---------------------------- | --------------------------------------------------- |
| Демо Toyota Camry, вариант 1 | `https://auto.drom.ru/demo/1.html`                  |
| Демо Toyota Camry, вариант 2 | `https://auto.drom.ru/demo/2.html`                  |
| Демо Toyota Camry, вариант 3 | `https://auto.drom.ru/demo/3.html`                  |
| Объявление недоступно        | `https://auto.drom.ru/demo/404.html`                |
| Источник запрещён            | `https://auto.drom.ru/demo/forbidden.html`          |
| Ошибка чтения объявления     | `https://auto.drom.ru/demo/parse-error.html`        |
| Источник временно недоступен | `https://auto.drom.ru/demo/source-unavailable.html` |

Для отдельной заполненной демонстрационной выборки установите `VITE_MOCK_SCENARIO=seeded` в `.env.local` и перезапустите Vite. Новая сессия получит три синтетические карточки. Сценарий `list-error` возвращает ошибку при первом запросе списка после инициализации обработчиков. «Повторить» загружает выборку.

### Детальная карточка

1. Откройте машину из выборки или откройте `/cars/car-1` в новой сессии сценария `seeded`. Измените цену через «Редактировать характеристики». Проверьте цену в карточке, состояние обоих подтверждений и денежные показатели в выборке.
2. Добавьте ремонт и обслуживание в «Необходимые вложения». Для одного расхода укажите `0`, для другого включите «Стоимость пока неизвестна». Отредактируйте сумму, затем удалите запись через подтверждение.
3. Добавьте преимущество, укажите его персональную ценность, затем попробуйте вариант с неизвестной ценностью. Для отсутствующего оснащения и преимущества с одинаковым `factor_key` mock-режим покажет ошибку. Используйте один способ учёта оснащения.
4. Подтвердите расходы и преимущества отдельно. В пустой группе используйте «Подтвердить отсутствие». Изменение расхода или преимущества сбрасывает подтверждение его группы. Неизвестная сумма оставляет оценку предварительной.
5. Добавьте заметку, измените её и проверьте денежные показатели. Перезагрузите карточку и вернитесь в выборку. Сохранённые факторы, заметки и подтверждения восстанавливаются из mock-данных.

Саммари показывает предполагаемые затраты на покупку и скорректированную стоимость отдельными строками. Последняя используется для сравнения выбранных автомобилей. Рыночную оценку Дрома можно посмотреть среди исходных данных автомобиля.

### Сравнение

1. В сценарии `seeded` отметьте Toyota Camry с ценами 1 200 000 ₽ и 1 270 000 ₽. Нажмите «Сравнить автомобили». Ожидаемые скорректированные стоимости — 1 340 000 ₽ и 1 250 000 ₽, разницы — 90 000 ₽ и 0 ₽.
2. По ссылке «Изменить состав» вернитесь в выборку и добавьте Camry за 1 320 000 ₽. Её разница составит 65 000 ₽. Исключите её над колонкой и убедитесь, что автомобиль остаётся в выборке.
3. Откройте расходы из таблицы, измените сумму и снова откройте сравнение. Состав восстанавливается при перезагрузке. «Очистить выбор» сбрасывает отметки.
4. На узком экране прокрутите таблицу по горизонтали. При её переполнении можно сфокусировать область клавишей Tab и прокручивать стрелками.

Пограничные состояния можно воспроизвести на двух новых машинах по [расчётным fixtures](../shared/fixtures/calculation-tests.json). Для полного результата подтвердите обе группы после ввода факторов.

| Предварительное         | Цена 100 000 ₽, расходы 10 000 ₽ и неизвестная сумма                     | Цена 120 000 ₽                                        | 0 ₽ и 10 000 ₽, предварительно           |

### Сессия и локальный сброс

Приложение восстанавливает токен из `localStorage` или создаёт анонимную сессию при его отсутствии. Ключ учитывает режим, базовый URL и mock-сценарий. MSW хранит отдельный набор автомобилей для каждого mock-токена. Клиент хранит только ID выбранных автомобилей в области локальной сессии. При недействительном токене приложение ждёт действия «Начать новую сессию», которое очищает прежние отметки сравнения.

Чтобы очистить только демоданные текущего origin, откройте консоль браузера на локальной странице приложения и выполните фрагмент ниже. Он удаляет mock-токены и демовыборки всех сценариев на этом origin, включая автомобили, добавленные вручную в mock-режиме.

```js
for (const key of Object.keys(localStorage)) {
  if (key.startsWith('drom-profit.session.v1.mock.') || key.startsWith('drom-profit.mock-db.v1.')) {
    localStorage.removeItem(key);
  }
}
location.reload();
```

## Конфигурация API

Используйте `.env.example` как образец для `.env.local`. После изменения переменных перезапустите Vite. Для `preview` потребуется новая сборка.

| Переменная           | Настройка                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| `VITE_API_MODE`      | `mock` или `real`. По умолчанию `mock` при `dev` и `real` при сборке                                   |
| `VITE_API_BASE_URL`  | HTTP(S) базовый URL. Пустое значение использует текущий origin в mock и `http://localhost:8000` в real |
| `VITE_MOCK_SCENARIO` | `empty`, `seeded` или `list-error`. Учитывается в mock-режиме                                          |

После готовности backend задайте `VITE_API_MODE=real` и его базовый URL. Сервер должен разрешить origin клиента через CORS. `VITE_*` публичны, токен передаётся при запросе из локальной сессии.

В дополнение к операциям сессии, импорта и выборки используются `PATCH /api/cars/{car_id}` для характеристик и подтверждений, `POST /api/cars/{car_id}/{expenses|benefits|notes}` и `PATCH`/`DELETE /api/cars/{car_id}/{expenses|benefits|notes}/{item_id}` для записей. `GET /api/cars/{car_id}/summary` используется в карточке и выборке. `POST /api/comparison` возвращает суммы, разницы, полноту и предупреждения для выбранных ID. Все шесть общих векторов проверяются на Mock API командой `npm run test`.

## Сборка и проверки

```sh
npm run typecheck
npm run lint
npm run test
npm run build
npm run preview
```

`npm run api:generate` обновляет типы из общего OpenAPI. `npm run tokens:generate` синхронизирует CSS с JSON-токенами и автоматически запускается при dev и build. В production-сборке `/ui-kit` показывает страницу 404. При размещении сборки настройте возврат `index.html` для клиентских маршрутов.
