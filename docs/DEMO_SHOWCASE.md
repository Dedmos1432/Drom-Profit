# Дром Профит · Демонстрационная витрина

Витрина INT-13 работает с Web в режиме real, Backend FastAPI и отдельной PostgreSQL. Demo Provider читает синтетические объявления из локальных файлов. Карточки, галереи и введённая оценка сохраняются через публичный API. Суммы и статусы приходят из серверных Summary и Comparison.

## Запуск на Windows

Нужны Docker Desktop в режиме Linux containers, Node.js из диапазона в `web/package.json` и Chrome. Освободите порты 8000 и 5174. Выделенный проект `drom-mvp-demo` использует свой том `drom-mvp-demo_postgres_data` и публикует только API на loopback.

### Терминал 1 · Backend и PostgreSQL

Локальный файл настроек и пароль сохраняются между запусками. Применяются существующие миграции по `0003_car_gallery` включительно.

~~~powershell
Set-Location 'C:\DromProfit\Drom-Profit-integration\backend'
$demoDir = Join-Path $env:LOCALAPPDATA 'DromProfit'
$demoEnv = Join-Path $demoDir 'showcase.env'
if (-not (Test-Path -LiteralPath $demoEnv)) {
    New-Item -ItemType Directory -Path $demoDir -Force | Out-Null
    $demoSecret = New-Object byte[] 32
    $demoRng = [Security.Cryptography.RandomNumberGenerator]::Create()
    try { $demoRng.GetBytes($demoSecret) } finally { $demoRng.Dispose() }
    $demoPasswordLine = 'POSTGRES_PASSWORD=' + (-join ($demoSecret | ForEach-Object { $_.ToString('x2') }))
    Set-Content -LiteralPath $demoEnv -Value $demoPasswordLine -Encoding ascii
    Remove-Variable demoSecret, demoPasswordLine
}
Remove-Item Env:POSTGRES_PASSWORD -ErrorAction SilentlyContinue
$env:DROM_LISTINGS_SOURCE = 'demo'
$env:DROM_LISTINGS_EXTRA_FIXTURE = '/srv/shared/fixtures/demo-showcase.json'
$env:DROM_CORS_ORIGINS = 'http://127.0.0.1:5174'
docker compose --env-file $demoEnv -p drom-mvp-demo up --build -d --wait api-loopback
(Invoke-RestMethod 'http://127.0.0.1:8000/openapi.json').info.version
~~~

### Chrome · подготовка отдельной сессии

Запустите Chrome с отдельным профилем. Сначала откройте страницу подготовки, так как главная страница создаёт обычную пустую сессию.

~~~powershell
$demoProfile = Join-Path $env:LOCALAPPDATA 'DromProfit\demo-chrome'
$demoChrome = Join-Path $env:ProgramFiles 'Google\Chrome\Application\chrome.exe'
if (-not (Test-Path -LiteralPath $demoChrome)) {
    $demoChrome = Join-Path ${env:ProgramFiles(x86)} 'Google\Chrome\Application\chrome.exe'
}
& $demoChrome "--user-data-dir=$demoProfile" 'http://127.0.0.1:5174/demo-showcase.html'
~~~

1. Нажмите **Подготовить витрину**. Страница создаст анонимную сессию, получит пять предпросмотров и запишет карточки, записи и флаги через API. Дождитесь сообщения о проверке Summary и Comparison.
2. Нажмите **Открыть выборку**. Web восстановит ту же сессию из локального хранилища. Токен передаётся к API в заголовке Authorization и остаётся в профиле браузера.
3. Для следующих показов открывайте главную страницу с тем же профилем, адресом Web и томом PostgreSQL. Повторное нажатие после подготовки сохраняет правки, удалённые позиции и дополнительные карточки в их текущем состоянии.
4. Если после начала записи подготовка прервётся, откройте частично заполненную выборку и заполните остаток вручную либо запустите Chrome с новым каталогом профиля и подготовьте отдельную сессию. Если сбой произошёл на предпросмотре, исправьте настройки Backend и повторите нажатие. Если в профиле уже есть обычная сессия, страница предложит другой профиль.

Страница подготовки доступна в локальном Vite. При ручной подготовке откройте главную страницу в отдельном профиле, сохраните каждый из пяти предпросмотров и внесите записи и подтверждения из таблицы.

## Чек-лист показа и приёмки

1. В подготовленной выборке проверьте пять карточек, иллюстрации и рассчитанные суммы. Откройте галерею и переключите все три изображения. На Camry покажите завершённую оценку. На Mazda проверьте неизвестную стоимость кондиционера. На Nissan покажите подтверждённые пустые расходы. На RAV4 откройте три заметки и проверьте начальную оценку.
2. Выберите Camry и Accord и нажмите **Сравнить автомобили**. Сверьте две скорректированные стоимости. Вернитесь в выборку, нажмите **Выбрать все** и сравните пять машин. Проверьте отметку предварительного сравнения, суммы и прокрутку таблицы на ширине 390 px.
3. Для проверки импорта и редактирования используйте второй каталог профиля Chrome. Обычная выборка начинается пустой. Импортируйте любую из пяти ссылок, проверьте предпросмотр, сохраните карточку, измените комплектацию, добавьте расход, преимущество и заметку. Обновите страницу, затем удалите эту копию. Подготовленная сессия доступна в первом профиле.
4. В Chrome DevTools на вкладке Network проверьте, что запросы `/api/` обслуживает `http://127.0.0.1:8000`, а фотографии загружаются с локального Web. На вкладке Application проверьте отсутствие зарегистрированного Mock Service Worker.
5. В первом терминале выполните команду перезапуска ниже. После ответа `/openapi.json` обновите страницу и повторно проверьте карточки, галереи и сравнение.

~~~powershell
docker compose --env-file $demoEnv -p drom-mvp-demo restart backend
docker compose --env-file $demoEnv -p drom-mvp-demo up --no-build -d --wait api-loopback
(Invoke-RestMethod 'http://127.0.0.1:8000/openapi.json').info.version
~~~

## Результаты проверки

- Linux Docker и PostgreSQL 17.6. Пройдены 445 серверных тестов. Read-only сверка подтвердила миграцию 0003_car_gallery, порядок трёх путей у каждого автомобиля, связи оценок с карточками, подтверждения и NULL у неизвестного расхода Mazda. Новые обычные сессии пусты и изолированы.
- Chrome real на desktop 1440 px и мобильной ширине 390 px. В отдельной сессии проверены все пять предпросмотров и сохранений, карточки, галереи, редактирование, добавление расходов, преимуществ и заметки, подтверждения, удаление и обновление страницы. Сравнение двух и пяти автомобилей соответствует контрольным значениям. После перезапуска Backend подготовленная сессия, галерея и сравнение сохранились. Запросы API обслужил локальный Backend, регистраций Mock Service Worker и запросов к Дрому не было.
- Web. Пройдены 111 тестов с командой npm run test -- --maxWorkers=2. Также прошли typecheck, lint и production build.

## Наблюдения для этапов 8.6.4.2–8.6.4.4

- При показе предпросмотра с фотографиями галерея и форма используют одинаковый React key. В режиме разработки появляется предупреждение о дублирующихся ключах. Импорт и сохранение работают.
- Подсказка в форме импорта показывает штатные примеры 1–3. Дополнительные ссылки витрины перечислены в этой инструкции.
- На 390 px рядом с закреплёнными названиями показателей полностью виден один автомобиль. Чтобы просмотреть остальные, прокрутите таблицу по горизонтали.

## Остановка

Остановите Vite через Ctrl+C во втором терминале. Затем остановите Compose в первом. Именованный том сохраняется. Для следующего запуска используйте те же имя проекта, файл настроек и профиль Chrome.

~~~powershell
Set-Location 'C:\DromProfit\Drom-Profit-integration\backend'
$demoEnv = Join-Path $env:LOCALAPPDATA 'DromProfit\showcase.env'
docker compose --env-file $demoEnv -p drom-mvp-demo down
~~~
