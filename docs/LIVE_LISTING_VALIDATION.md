## Правила транспорта

Провайдер проверяет HTTPS, точный входной хост, отдельный список хостов для межхостовых редиректов, публичные DNS-адреса и совпадение IP пира. TLS проверяет сертификат по исходному имени. Редиректы проверяют формат ссылки и идентификатор объявления. Общие 15 секунд включают ожидание слота и сетевой запрос. Лимиты составляют три редиректа, 2 000 000 байт и четыре одновременно выполняемых запроса на процесс. Запросы используют обычный HTTPS, без прокси, cookies и авторизации. Автоматические повторы отсутствуют. [Реализация и ограничения Parser](../backend/app/services/listings/README.md#реальный-источник)

| Случай | Действующий ответ API |
|---|---|
| Недопустимый входной URL | 400 `invalid_url` |
| HTTP 403, HTTP 429 или распознанная страница CAPTCHA | 403 `source_forbidden` |
| HTTP 404/410 или переход со страницы снятого объявления на поиск того же сайта | 404 `listing_unavailable` |
| Нераспознанный HTML, неверная цена, неподдерживаемая валюта, смена ID в редиректе | 502 `parse_error` |
| DNS, TLS, таймаут, источник 5xx, уход на хост вне списка | 503 `source_unavailable` |

Если однозначно распознанная карточка не содержит цены, предпросмотр возвращает `price: null`. Для сохранения пользователь вводит цену вручную. [Денежный контракт](MONEY_CONTRACT.md)

## Ручной запуск после разрешения

Используйте Docker Compose 2.33.1 или новее с Linux-контейнерами. Освободите `127.0.0.1:8000` и `localhost:5173`. При первом запуске создайте `backend/.env` с локальным `POSTGRES_PASSWORD` по инструкции Backend. Сохраните тот же пароль для повторного запуска с тем же томом. Хосты и флаг задавайте локально. Имя `drom-mvp-live` отделяет тестовую PostgreSQL от других проектов. [Подготовка .env](../backend/README.md#создание-локального-env)

Backend в первом терминале PowerShell. Пример рассчитан на согласованный входной хост `auto.drom.ru`. При согласованных межхостовых редиректах укажите соответствующие точные хосты.

```powershell
Set-Location 'C:\DromProfit\Drom-Profit-integration\backend'
$env:DROM_LISTINGS_SOURCE = 'drom'
$env:DROM_LISTINGS_ACCESS_APPROVED = 'yes'
$env:DROM_LISTINGS_HOSTS = 'auto.drom.ru'
$env:DROM_LISTINGS_REDIRECT_HOSTS = ''
$env:DROM_CORS_ORIGINS = 'http://localhost:5173'
docker compose -p drom-mvp-live -f compose.yaml -f compose.live.yaml up --build -d --wait api-loopback
docker compose -p drom-mvp-live -f compose.yaml -f compose.live.yaml ps -a
(Invoke-RestMethod http://127.0.0.1:8000/openapi.json).info.version
```

Web во втором терминале PowerShell.

```powershell
Set-Location 'C:\DromProfit\Drom-Profit-integration\web'
npm.cmd ci
$env:VITE_API_MODE = 'real'
$env:VITE_API_BASE_URL = 'http://127.0.0.1:8000'
npm.cmd run dev -- --host localhost --port 5173 --strictPort
```

Откройте [локальный Web](http://localhost:5173/) в новой сессии Chrome. Вставьте одну согласованную ссылку из проверенных образцов. Проверьте состояние загрузки и поля предпросмотра, затем отредактируйте цену или характеристику и явно сохраните автомобиль. Добавьте расход и преимущество, проверьте карточку, Summary и Comparison со второй карточкой. Обновите страницу и проверьте сохранение данных. Ошибку импорта и последующий ручной ввод можно проверить на локальном подставном ответе.

Для разрешённого запроса запишите исходный URL, HTTP-статус, Content-Type, кодировку, факт редиректа, время и объём ответа, результат разбора, число полей, наличие основного снимка, размер галереи и код при ошибке. Начните с одного объявления, остальные проверяйте последовательно в рамках разрешённых лимитов. Если источник отдаёт CAPTCHA, 403 или 429, остановите сетевую проверку и запишите причину. Храните только необходимые обезличенные метаданные и значения. Исходный HTML, фото, полные заголовки, cookies и контакты не входят в отчёт.

Для остановки нажмите Ctrl+C в терминале Web. Затем выполните эти команды в терминале Backend. Том PostgreSQL сохраняется.

```powershell
Set-Location 'C:\DromProfit\Drom-Profit-integration\backend'
docker compose -p drom-mvp-live -f compose.yaml -f compose.live.yaml down
Remove-Item Env:DROM_LISTINGS_SOURCE, Env:DROM_LISTINGS_ACCESS_APPROVED, Env:DROM_LISTINGS_HOSTS, Env:DROM_LISTINGS_REDIRECT_HOSTS -ErrorAction SilentlyContinue
```

## Условия публичного выпуска

Нужно письменно согласовать источник, входные и переходные хосты, лимиты запросов и права на фотографии. Затем подтвердить DNS, TLS, редиректы, ошибки и отображение снимка на разрешённых ответах, повторить сценарий Chrome и согласовать хосты с Android. INT-07 остаётся `Partial`, INT-14 и INT-15 имеют статус `Blocked`. INT-10 отложен до пост-MVP. [Интеграционный бэклог](INTEGRATION_BACKLOG.md)
