# Архитектура и распределение работ

`Web → REST JSON → Core Backend → PostgreSQL`. Web использует React, TypeScript и Vite. Core работает на FastAPI с Pydantic, SQLAlchemy и Psycopg. PostgreSQL 17.6 хранит сессии, карточки, расходы, преимущества, заметки и порядок фото. Alembic применяет миграции до `0003_car_gallery`. Docker Compose запускает отдельную базу и API. Для демонстрационного проекта на хост публикуется только API на loopback.

- **Core** обслуживает анонимные сессии, проверяет Bearer и принадлежность ресурсов, рассчитывает Summary и Comparison. Web сохраняет токен между запусками в профиле браузера.
- **Parser** работает внутри Backend в `backend/app/services/listings/`. Core вызывает поставщик объявления и возвращает нормализованные данные предпросмотра или REST-ошибку. Demo Provider читает синтетические fixtures. Сетевой источник требует отдельного согласования и явной настройки.
- **Web real** получает данные и расчёты из API. **Web mock** выполняет сценарии на локальных фикстурах. Подготовка real-витрины создаёт отдельную сессию через публичный API.
- **Android Kotlin/Compose** находится в `review/android-integration`. Работа Kotlin-клиента с API проверена на JVM. Приёмка APK и устройства остаётся открытой. Текущий `integration/mvp` содержит инструкции Android.

## Контракты и данные

`shared/openapi.yaml` описывает OpenAPI 0.3.0. `POST /api/cars/import` возвращает `ListingData` для предпросмотра. `POST /api/cars` сохраняет подтверждённую карточку. `POST /api/comparison` принимает `car_ids`. Идентификаторы ресурсов строковые. Для неизвестных значений используется `null`.

Предпросмотр и детальная карточка передают `image_url` и упорядоченный `image_urls`. Порядок хранится в `cars.image_urls`. Список использует основное фото. Демонстрационные JPG доставляются из Web. [Контракт галереи](PHOTO_GALLERY_CONTRACT.md)

Backend рассчитывает `C = P + R`, `E = C − B`, полноту и разницы внутри выборки. Деньги передаются целыми рублями, Web в real показывает серверные результаты. [Денежный контракт](MONEY_CONTRACT.md) · [Правила расчёта](calculation-rules.md)
