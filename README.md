# Дром Профит

Дром Профит помогает покупателю подержанного автомобиля собрать отобранные им машины в одну выборку и сравнить варианты. Цена объявления видна сразу, а необходимый ремонт, оснащение и замечания по истории и осмотру приходится учитывать отдельно. Приложение объединяет эти данные и показывает, насколько они меняют сравнение.

## Возможности и статус MVP

- Выборка сохраняется в анонимной сессии. Автомобили можно добавить вручную либо импортировать из демонстрационного объявления, проверить и отредактировать до сохранения.
- Карточка показывает фотографии, характеристики, расходы, преимущества и заметки. Для суммы можно указать, что она неизвестна, и отдельно подтвердить рассмотренные группы.
- Summary показывает итоги по одной машине. Comparison сравнивает два и более варианта и объясняет предварительный статус и предупреждения.

Демонстрационная ветка `integration/mvp` включает Web, Core Backend, Demo Parser и PostgreSQL. Web `real` использует локальный сервер и сохраняет изменения в БД. Web `mock` воспроизводит сценарии на локальных данных. Код Android находится в `review/android-integration` и проходит отдельную приёмку. Kotlin-клиент проверен на JVM на этапе 8.7.3, APK и запуск на устройстве остаются открытыми. [Готовность демонстрации и PR](docs/MVP_RELEASE_READINESS.md)

## Архитектура и репозиторий

Web на React, TypeScript и Vite обращается по REST JSON к FastAPI. Backend использует Pydantic, SQLAlchemy, PostgreSQL 17.6 и Alembic, а Parser работает внутри Backend. Docker Compose запускает сервер и базу. Контракт API — OpenAPI 0.3.0. [Архитектура](docs/architecture.md)

## Экономическая модель

`P` — цена автомобиля, `R` — сумма известных необходимых расходов, `B` — сумма известной персональной ценности преимуществ. `C = P + R` — предполагаемые затраты на приобретение. `E = C − B` — скорректированная стоимость для сравнения. E зависит от введённых пользователем сумм. Фактическая цена сделки определяется условиями покупки, а рыночная оценка требует отдельных данных. Неизвестная сумма хранится как `null`. Ноль означает явно заявленное нулевое значение. При неизвестных суммах или неподтверждённых группах оценка предварительная. [Правила расчёта](docs/calculation-rules.md) · [Денежный контракт](docs/MONEY_CONTRACT.md)

## Быстрый запуск на Windows

Нужны Docker Desktop с Linux-контейнерами, Compose 2.33.1+, Chrome, npm и Node.js из диапазона в `web/package.json`. Проверьте свободные loopback-порты 8000 и 5174. При первом запуске создайте локальный `showcase.env` и отдельный профиль Chrome по инструкции. [Подготовка с нуля](docs/DEMO_SHOWCASE.md#запуск-на-windows)

Из каталога `backend`:

```powershell
$demoEnv = Join-Path $env:LOCALAPPDATA 'DromProfit\showcase.env'
Remove-Item Env:POSTGRES_PASSWORD -ErrorAction SilentlyContinue
$env:DROM_LISTINGS_SOURCE = 'demo'
$env:DROM_LISTINGS_EXTRA_FIXTURE = '/srv/shared/fixtures/demo-showcase.json'
$env:DROM_CORS_ORIGINS = 'http://127.0.0.1:5174'
docker compose --env-file $demoEnv -p drom-mvp-demo up --build -d --wait api-loopback
```

Во втором терминале из каталога `web`:

```powershell
npm.cmd ci
$env:VITE_API_MODE = 'real'
$env:VITE_API_BASE_URL = 'http://127.0.0.1:8000'
npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

В отдельном профиле Chrome откройте [подготовку витрины](http://127.0.0.1:5174/demo-showcase.html). Нажмите **Подготовить витрину**, дождитесь сообщения об успехе и откройте выборку. Для повтора используйте тот же профиль, адрес и PostgreSQL-том. [Повторный запуск и остановка](docs/INTEGRATION_RUNBOOK.md#быстрый-демонстрационный-запуск)

## Демонстрационная витрина

Toyota Camry, Honda Accord, Mazda 6, Nissan X-Trail и Toyota RAV4 имеют по три локальные иллюстрации. Подготовка записывает оценки через API в отдельной сессии. Для изменения данных во время показа используйте тестовую карточку в другом профиле Chrome. [Контрольные результаты](docs/DEMO_SHOWCASE.md) · [Сценарий на 5–7 минут](docs/PRODUCT_DEMO.md)

## API и тестирование

Локальный адрес API — `127.0.0.1:8000`. Доступны [Swagger UI](http://127.0.0.1:8000/docs), [работающий контракт](http://127.0.0.1:8000/openapi.json) и [общий OpenAPI YAML](shared/openapi.yaml).

- Backend проверяется pytest в отдельной PostgreSQL через Compose-профиль `test`. [Команды](backend/README.md#тесты)
- Web из `web` — `npm.cmd run test -- --maxWorkers=2`, `npm.cmd run typecheck`, `npm.cmd run lint` и `npm.cmd run build`. [Инструкция Web](web/README.md)
- Ранее прошли 445 Backend-тестов и 111 Web-тестов. Этап 8.9 проверяет запуск и готовность демонстрационной витрины. [Результаты этапа](docs/MVP_RELEASE_READINESS.md)

## Ограничения и документация

Объявления и записи витрины синтетические. Сетевой импорт настоящих объявлений и использование оригинальных фотографий Дрома ожидают письменного согласования. Семантика рыночной оценки требует подтверждения. В MVP доступны заметки по осмотру и истории автомобиля, автоматический анализ отчётов и диагностика вне текущего объёма. Пользовательские аккаунты, межплатформенная синхронизация и справочник `factor_key` отложены. Android проходит отдельную приёмку. Дальнейший функциональный аудит Web зависит от обратной связи.
