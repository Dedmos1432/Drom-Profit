# Drom Profit для Android

Откройте каталог `android/` в Android Studio. Для сборки нужны JDK 21 и Android SDK API 37. Минимальная версия для запуска приложения — Android 8.0 (API 26).

## Запуск

Из каталога `android/` в PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Запустите конфигурацию `app` в Android Studio или установите APK командой `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

Если `java` отсутствует в PATH, задайте `JAVA_HOME` на JDK 21 или на встроенную JBR 21 Android Studio.

Миграцию и сохранение через Room проверяет инструментальный тест. С подключённым устройством или запущенным эмулятором выполните `.\gradlew.bat :app:connectedDebugAndroidTest`.

## Демонстрационный режим

Debug без URL API использует `shared/fixtures`. При первом запуске в выборке три синтетических автомобиля. Выборка и пользовательские правки сохраняются в локальной базе Room. При первом запуске с Room ранее сохранённая демовыборка переносится из файла.

- На экране добавления нажмите «Вставить демоссылку», затем «Получить данные». Проверьте предпросмотр, скорректируйте характеристики и сохраните автомобиль.
- Проверьте ручной ввод и переход к нему после ошибки импорта. Для первого запуска с пустой выборкой соберите с `-PdromProfitDemoEmpty=true` и установите APK. У этого режима своё хранилище, поэтому ранее сохранённая демовыборка доступна при возвращении к обычной сборке.
- Откройте карточку. Добавьте ремонт, ТО, преимущество или заметку. Проверьте случай с неизвестной суммой и подтверждение полноты расходов и преимуществ.
- В разделе «Сравнение» отметьте минимум два автомобиля и откройте результаты. Для первых двух исходных демоавтомобилей разница составляет 90 000 ₽ при указанном в fixtures наборе факторов.
- Проверьте редактирование характеристик, удаление с подтверждением и сохранение выборки после перезапуска.

## Подключение backend

Сборка для Android-эмулятора с запущенным на компьютере API на порту 8000:

```powershell
.\gradlew.bat :app:assembleDebug "-PdromProfitApiBaseUrl=http://10.0.2.2:8000/"
```

Для тестового сервера подставьте согласованный HTTPS URL. Незашифрованное соединение доступно в debug только для локальной разработки. Для рабочего release требуется HTTPS URL. Retrofit обращается к маршрутам `/api` из общего OpenAPI. Адрес может содержать префикс пути.

При первом обращении клиент создаёт анонимную сессию и хранит Bearer-токен в приватном хранилище. При ответе `401` новую сессию можно создать из выборки после подтверждения. Сохранённая выборка привязана к прежней сессии. Сетевой режим показывает серверные итоги и предупреждения. Доступность живого импорта зависит от подключённого серверного источника. Для фото в текущей версии используется заглушка. Сведения из отчёта об истории вводятся вручную.

## Архитектура

Модуль использует Clean Architecture и MVVM. Направление зависимостей исходного кода идёт к `domain`.

| Слой | Ответственность |
| --- | --- |
| `presentation/screens` | Compose-экраны по сценариям и предпросмотры |
| `presentation/viewmodels` | Состояния `StateFlow`, действия пользователя и вызовы use cases |
| `presentation/components` и `presentation/navigation` | Общие компоненты и маршруты |
| `domain/repository` | Интерфейс `CarRepository` и ошибки репозитория |
| `domain/usecases` | Чистые Kotlin-сценарии в отдельных пакетах |
| `data/local` | База Room, сущности, DAO и преобразование локальных записей |
| `data` | Реализации репозитория, Retrofit, преобразование JSON и приватное хранение сессии |
| `di` | Hilt связывает реализации с доменными сценариями |

В сетевом режиме Room хранит полученную с сервера выборку отдельно для каждой анонимной сессии и адреса API. Для актуальных данных и расчёта приложение обращается к серверу. Реализация демонстрационного источника входит в debug. Общие fixtures читаются как Android assets. Сетевой клиент передаёт только явно изменённые поля `PATCH`, включая явный `null` при очистке допустимого поля. Денежные значения отображаются в целых рублях.

Тема Android использует согласованную светлую веб-палитру Drom Profit. Для текста основной кнопки на синей заливке выбран вариант `#1766B0`, для названия продукта — красный `#DB001A`. Основные отступы экрана — 16 dp, высота основного действия — от 52 dp, минимальная зона нажатия — 48 dp.
