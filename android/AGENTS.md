# Android — Dedmos
Прочитай корневой AGENTS.md, docs/ и shared/openapi.yaml. Зона: android/ (или уже существующий согласованный Android-каталог). Ветка feature/android-mvp; сохрани текущую ветку и UI Kit, если работа уже начата.

- Kotlin, Jetpack Compose, ViewModel; Retrofit/OkHttp для API. Сохрани текущую архитектуру и компоненты UI Kit.
- Сначала UI Kit и навигация, затем выборка, импорт по ссылке с подтверждением, ручное добавление, карточка, расходы/преимущества/заметки, сравнение.
- Используй отдельный API client; до готовности сервера — mock, совместимый с OpenAPI и fixtures. Не реализуй самостоятельный production-калькулятор.
- Храни токен анонимной сессии в приватном хранилище приложения; не логируй его. Серверный base URL конфигурируемый. Для эмулятора локальный сервер обычно доступен через 10.0.2.2; HTTP только в debug при необходимости.
- Состояния загрузки, ошибки, пустая выборка, неизвестные данные и предварительная оценка. Для сравнения двух и более авто — читаемый мобильный интерфейс.
- Не меняй web/backend. Передай команде дизайн-токены UI Kit (цвета, типографика, отступы, состояния) через согласованный файл/PR.
- Готовность: сборка debug APK, проверка основного сценария, инструкция запуска и настройки API.
