# Core Backend — разработчик №3
Прочитай корневой AGENTS.md, docs/ и shared/openapi.yaml. Работай в feature/backend-core. Зона backend/, кроме app/services/listings/ и tests/listings/ (ими владеет разработчик №4).

- FastAPI, Pydantic, SQLAlchemy, SQLite. Простое монолитное приложение; версионирование схемы БД согласовать. Конфигурация из окружения, CORS только для согласованных origins.
- Реализуй контракт: анонимные сессии, CRUD автомобилей, расходов, преимуществ, заметок; расчет саммари и сравнение. Изолируй данные по владельцу, включая вложенные ресурсы; не доверяй client session_id. Токены случайные криптографически стойкие, на сервере хранить хеш, не логировать; HTTPS при публичном размещении.
- Реализуй правила расчета и тесты из fixtures/calculation-tests.json, включая null, явное подтверждение полноты, двойной учет, равенство и смешанную полноту.
- Импорт — preview без сохранения, делегируется listings через согласованный интерфейс. До готовности модуля используй stub вне чужого каталога.
- Согласуй контракт до изменения публичных схем. Подготовь команды запуска, тестов и настройку БД. Не разрабатывай frontend, Android или обработку PDF.
- Готовность: сервер запускается, OpenAPI соответствует контракту, тесты расчетов, валидации и доступа между сессиями проходят.
