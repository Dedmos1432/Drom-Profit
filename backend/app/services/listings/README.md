# Импорт объявлений (`app.services.listings`)

Зона Data Integration (разработчик №4). Модуль принимает ссылку на объявление и
возвращает структуру `ListingData` из `shared/openapi.yaml`. Он не обращается к БД,
не создает сессии, не сохраняет данные и не рассчитывает рыночную цену.

Зависимости — только стандартная библиотека Python 3.13+; в `requirements.txt` ничего
не добавляется.

## Интерфейс

```python
from app.services.listings import ListingData, ListingImportError, importer_from_env

importer = importer_from_env()        # ListingImporter: async (url: str) -> ListingData
listing = await importer(url)         # ошибки источника — ListingImportError
listing.as_dict()                     # dict из 18 полей контракта, порядок как в схеме
importer.source                       # "demo" или "drom"
```

| Объект | Назначение |
|---|---|
| `ListingData` | неизменяемый dataclass, проверяет типы и ограничения контракта; `as_dict()` / `from_dict()` |
| `ListingImporter` | вызываемый объект `async (url) -> ListingData`; посторонние ошибки разбора превращает в `parse_error` |
| `ListingImportError(code, detail)` | `code` — машинный код; `detail` — текст для логов, не для пользователя |
| `make_importer(...)` | явное создание с режимом, путём fixtures или точными хостами |
| `importer_from_env(environ)` | создание по переменным окружения (ниже) |
| `import_listing(url)` | функция-обертка над `importer_from_env()` для простых вызовов |

### Ошибки

| `code` | HTTP (переводит Core) | Когда |
|---|---|---|
| `invalid_url` | 400 | не https, чужой хост, порт, учетные данные, IP, не путь `*.html`, управляющие символы, > 2048 символов |
| `listing_unavailable` | 404 | нет в demo-наборе; HTTP 404/410; снято с продажи; перенаправление на не-объявление того же сайта |
| `source_forbidden` | 403 | HTTP 401/403/407/429/451; страница CAPTCHA или блокировки |
| `parse_error` | 502 | неподходящий HTML, лимит размера, ошибка сопоставления машины или предложения, нет марки, модели и цены |
| `source_unavailable` | 503 | DNS/сеть/TLS/таймаут, HTTP 5xx, непубличный адрес, перенаправление на чужой хост, лимит перенаправлений |

## Конфигурация

| Переменная | По умолчанию | Значение |
|---|---|---|
| `DROM_LISTINGS_SOURCE` | `demo` | `demo` или `drom`; смешивания нет |
| `DROM_LISTINGS_FIXTURE` | `<repo>/shared/fixtures/import-listings.json` | путь к demo-набору |
| `DROM_LISTINGS_ACCESS_APPROVED` | пусто | `yes` после получения разрешения на автоматизированный доступ |
| `DROM_LISTINGS_HOSTS` | пусто | обязательные в режиме `drom` точные входные хосты через запятую |
| `DROM_LISTINGS_REDIRECT_HOSTS` | пусто | точные хосты межхостовых редиректов через запятую. Редиректы на текущем разрешённом хосте проходят обычную проверку пути |

## Подключение к Core Backend

Адаптер Core создаёт экземпляр Parser один раз при сборке
FastAPI и возвращает `app.schemas.ListingData` через
`ListingData.model_validate(data.as_dict())`. Сборка приложения использует
`DROM_LISTINGS_SOURCE=demo`. В тестах доступно внедрение через `create_app(importer=...)`. [Адаптер Core](../listing_import.py)

Core возвращает соединение PostgreSQL после проверки Bearer. Вызов Parser
асинхронный. `POST /api/cars/import` возвращает предпросмотр, затем клиент сохраняет
карточку отдельным `POST /api/cars`. Ошибки Parser преобразуются по коду.
Невалидный результат возвращает `502 parse_error`. Формат API содержит только
`code` и пользовательское `message`. Команды Docker приведены в [README Core](../../../README.md).

## Demo-режим

Источник — `shared/fixtures/import-listings.json`. Каждая запись обязана иметь
`source = "demo"` и уникальный `listing_url`. Разрешены только хосты из самих fixtures
(`auto.drom.ru`), query и fragment игнорируются. Остальные ссылки Дрома в demo-режиме
дают `invalid_url` (другой хост) или `listing_unavailable` (неизвестный путь). Сеть
не используется.

## Нормализация

- Цена HTML передаётся в целых рублях при явно указанной валюте `RUB` или `RUR`.
  Если формат разрешённого источника гарантирует рубли без отдельного поля, это
  правило нужно подтвердить на образцах и согласовать. Пока пропущенная, неизвестная
  и неподдерживаемая валюта дают `null` на этапе разбора полей. HTML-провайдер
  возвращает `parse_error`, если положительную рублёвую цену подтвердить не удалось.
- HTML принимает распознанные коды или обозначения для км, тыс. км, л, см³, л. с.
  и кВт. Мили, неизвестная или противоречивая единица, число без единицы и текст
  без обозначения единицы дают `null`. Исходные числа без единиц по-прежнему
  принимаются нормализатором на тех внутренних вызовах, где единицы уже известны.
- Фильтры HTML строже схемы API. Год ограничен следующим календарным годом,
  пробег — 5 млн км, мощность — 1–3000 л. с., объём до округления — больше 0
  и меньше 20 л. OpenAPI задаёт только нижние границы и допускает ноль для
  объёма и мощности. Эти локальные фильтры нужно сверить на разрешённых образцах.
- Словари топлива, коробки и привода приводят известные варианты к строкам
  fixtures. Прочие непустые строки сохраняются после очистки. Эти поля в API строки.
- `market_valuation` остаётся `null`. Для заполнения нужен согласованный источник
  опубликованной оценки Дрома с полем, единицами и примером отсутствующего значения.

## Сохранённые объявления

Проверены шесть сохранённых HTML-страниц Windows-1251. Parser связывает Car с объявлением через совпадающий `Offer.url`, если сам Car не содержит идентификатора. Для подтверждённой страницы дополнительные данные извлекаются из таблицы, блока города и галереи. Сетевой доступ ожидает согласования. [Проверка сохранённых объявлений](../../../../docs/REAL_LISTING_VALIDATION.md)

## Реальный источник

По умолчанию включён demo. HTML-провайдер требует `DROM_LISTINGS_ACCESS_APPROVED=yes`
и настроенный список `DROM_LISTINGS_HOSTS`. Значения задаются после согласования.
Допустима одна метка перед `drom.ru`. Шаблоны, корневой домен и произвольные хосты
отклоняются при старте. Межхостовые редиректы требуют отдельных записей в
`DROM_LISTINGS_REDIRECT_HOSTS`.

- DNS, соединение, TLS, заголовки, тело и до трёх редиректов выполняются в одном
  короткоживущем процессе. Общие 15 с включают ожидание слота. По истечении
  оставшегося бюджета родитель завершает процесс и дожидается его выхода.
  Блокирующий вызов DNS или чтение не остаются в потоке backend. Таймауты сокета
  остаются ограничениями отдельных операций: 5 с на подключение, 10 с на чтение
  в пределах общего бюджета. Запуск процесса операционной системой и его
  завершение могут добавить накладное время. В развёртывании Python должен
  иметь возможность создавать дочерний процесс. Разбор HTML выполняется после
  сетевого ответа и в сетевой бюджет не входит.
- Каждый DNS-результат должен быть публичным. Соединение закрепляется за
  выбранным IP с проверкой пира и сертификата по исходному имени. Прокси,
  cookies и авторизация не используются.
- Клиент классифицирует статус по заголовкам. Только для успешного HTML читает
  тело до 2 000 000 байт, запрашивает `Accept-Encoding: identity` и отклоняет
  неожиданное сжатие. Полный транспорт проверяется локальными подстановками и
  тестами жизненного цикла процесса. Совместимость с разрешённым реальным
  источником и его средой запуска ещё предстоит подтвердить.
- При известном числовом ID редирект сохраняет его. Для ссылок без числового
  ID изменение канонического URL отклоняется. В JSON-LD нужна однозначная
  связь объекта с конечным URL или числовым ID. При нескольких предложениях
  выбирается единственное подтверждённое. Если нужный объект или предложение
  не удаётся определить, импорт возвращает `parse_error`. Поддерживаются
  вложенные `offers`, локальные ссылки и поля идентификации из синтетических
  тестов. Схема JSON-LD Дрома, его идентификаторы и страницы без структурированных
  данных пока не подтверждены.

## Фотографии

Парсер проверяет кандидатов `image` в порядке источника. Строки URL, `url` и
`contentUrl` объектов проходят проверку HTTPS. Относительный путь разрешается
в пределах хоста конечной страницы. Если в структурированных данных нет
подходящего адреса, используются допустимые `og:image`. Повторы исключаются,
параметры адреса сохраняются, фрагменты удаляются. Тело изображения сервер
не загружает. Публичный `image_url` содержит первый кандидат или `null`. Для подтверждённой страницы ссылки основной галереи имеют приоритет и сохраняют исходный порядок без повторов.

Предложение к согласованию — необязательное `image_urls: string[]` с уникальными
адресами в порядке источника и главным снимком первым. `image_url` остаётся
главным фото для совместимости. При `additionalProperties: false` необходим
согласованный выпуск схемы и потребителей Backend, Web и Android. Отдельно
согласуются права на фото, срок жизни прямого URL и необходимость доставки
через разрешённую инфраструктуру.

## Тесты

Из каталога `backend/` в изолированном Python-окружении с установленным `pytest` выполните отдельный прогон Parser. Для объединённого прогона Core и Parser используйте Docker-профиль `test` из README Core.

```powershell
python -B -m pytest -q -p no:cacheprovider tests/listings
```

Тесты используют локальные fixtures, синтетический HTML и подставные DNS и HTTP.
Тест границы процесса запускает локальную программу без сети.
